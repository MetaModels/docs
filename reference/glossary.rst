MetaModels Glossary
===================

.. glossary::
	:sorted:

	MetaModels
		MetaModels (plural) represents the complete structure with the interaction
		of multiple MetaModel instances with each other

	MetaModel
		MetaModel (singular) represents a data table with its attributes,
		input/output options, filters, etc., as well as display permissions
